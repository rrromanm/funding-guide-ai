# REQUIREMENTS

1. As a PYN Admin, I want funding opportunities from selected sources to be collected automatically, so that I can reduce the time spent searching for new opportunities. 

2. As a PYN Admin, I want to add a funding opportunity manually, so that I can store opportunities that cannot be collected automatically. 

3. As a PYN Admin, I want to edit or delete a stored funding opportunity, so that incorrect or obsolete records do not mislead my decisions. 

4. As a PYN Admin, I want to see closed recurring calls and when they are expected to reopen, so that I can prepare before the next round opens. 

5. As a PYN Admin, I want to view the details of a funding opportunity, so that I can understand its requirements, deadline, budget, eligibility, and other important information. 

6. As a PYN Admin, I want to search and filter funding opportunities, so that I can quickly find opportunities that match what I am looking for. 

7. As a PYN Admin, I want to create and update PYN's organizational profile, so that the system can provide recommendations based on the organization's current situation. 

8. As a PYN Admin, I want to see a match score and explanation for each funding opportunity, so that I can understand how well the opportunity fits PYN. 

9. As a PYN Admin, I want to manually override or dismiss a recommendation I disagree with, so that an incorrect recommendation does not affect my planning. 

10. As a PYN Admin, I want to be notified when a new relevant funding opportunity is found, so that I do not miss opportunities that may fit PYN. 

11. As a PYN Admin, I want to log in to the system, so that PYN's organizational information and saved opportunities are not publicly accessible. 

# FUTURE IMPROVEMENTS (if time to implement)

12. As a PYN Admin, I want the system to detect and avoid duplicate funding opportunities, so that the list of opportunities stays trustworthy. 

13. As a PYN Admin, I want to sort funding opportunities by match score and deadline urgency, so that I can focus on the most important opportunities first. 

14. As a PYN Admin, I want to save funding opportunities to a watchlist and mark them as priority, maybe later, or not relevant, so that I can organize them based on PYN's interest. 

15. As a PYN Admin, I want to receive reminders before funding opportunity deadlines, so that I have enough time to prepare an application. 

16. As a PYN Admin, I want to see possible strengths, barriers, and the confidence of the recommendation, so that I can judge whether the opportunity is realistic for PYN. 

17. As a PYN Admin, I want to know whether PYN should apply as a lead applicant or join as a partner, so that I can choose the most suitable role for each opportunity. 

18. As a PYN Admin, I want to see when each funding source was last checked successfully, so that I can identify when a source may not be working correctly. 

19. As a PYN Admin, I want to see the likely application language for a funding opportunity, so that I can plan the application process and workload. 

20. As a PYN Admin, I want to be warned when a funding opportunity is too advanced or administratively demanding for PYN, so that I do not spend time on unrealistic applications.
